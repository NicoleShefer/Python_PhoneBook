# PhoneBook Test Automation

An educational project on automated web testing of the "Phonebook" application.

## Goal
Learn how to design, run, and maintain automated UI tests in Python.

## Application under test
https://telranedu.web.app

## Tech stack
- **Python**: the main programming language
- **Selenium WebDriver**: automating browser actions
- **pytest**: test framework for writing and running tests
- **Google Chrome**: the browser the tests run in
- **Git / GitHub**: version control and code hosting
